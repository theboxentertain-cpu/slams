## First five minutes

The current blueprint's short supported route is Welcome → **Enter the Studio** → Account Choice → **Skip to the Office** → **Start rehearsal** → briefing → **Begin take** → acting choices. The account/setup process is optional; the existing guest-setup-baseline path is longer. The audited first-action hierarchy remains open work rather than being silently replaced with the unmerged PR B route.

Once in the scene: choose an authored tactic, read the fixed response, choose a technique intervention, write the exercise observation, try the changed obstacle, write a retake, review the actual choices and reflect. This PR adds useful in-flow repetition: Back to exercise retains the exercise and retake; Practice again retains the reflection while editing the current retake. These controls do not create separate captured takes or a three-take comparison.

Save only succeeds after the existing store confirms it. The record then opens Passport or returns to the Hub. Alternatively, the explicit unsaved return creates no record and explains the discard. Guest storage is browser-local and can be cleared; saving it is not cloud synchronization or competence verification.

Browser automation checks supported choices, return paths, retained input and persistence. It does not establish that a human completed a valuable learning experience within five minutes. Manual operator/human usability research is **NOT RUN**.
