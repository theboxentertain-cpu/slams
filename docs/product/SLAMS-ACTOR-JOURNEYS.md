## C — Working actor

Planned character/project/media tools are disclosed separately; old bookmarks lead to honest statuses and an available preparation/rehearsal/history action. Related-evidence modeling and richer project workflows remain PR D work.

## D — Stuck actor

After PR A: `/stuck` → existing authored draft question/option → practical suggestion and its review disclaimer → actual Living Scene. The redundant `/stuck/intervention` bookmark redirects here. Old scene/identify query states explain their limitation and return to available suggestions. Persisted problem intake, linked retry comparison and saved fixes are still unavailable. A machine has not observed or diagnosed the actor.

## E — Returning actor

Entry preference/actual session retains Office. Available actions are a saved reviewed-unit resume, new scripted rehearsal, saved Passport reflection or audition preparation. A finished Passport entry remains a completed record, not a resumable draft. Unknown cloud activity stays unknown. Live cross-device/authenticated behavior still requires the separate verification gates.

All journeys preserve existing user records, account boundaries and first-visit/deep-link behavior. Guest browser checks and authenticated unit/database simulations must be reported separately from real confirmed-account testing.
